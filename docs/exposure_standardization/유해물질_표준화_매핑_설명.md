# 유해물질 표준화 매핑 — 설명

산출물: **`유해물질_표준화_매핑.tsv`** (원표기 393행 = 감사 가능한 동의어 사전).
소스: `측정값.물질`(최종·검토완료) 원표기 393종. 표준 레지스트리: ohsearch `ExposureFactor`(220종, CAS 89·IARC·법적근거·계층 보유).

## 결과 요약
- **393 원표기 → 117 표준 유해인자 + 35 비유해인자**로 수렴.
- 표준명 부여 **354종** / CAS 확보 **148종** / 미매핑 **0**.
- 표준화된 (물질·사례) 쌍: **840/879**.

## 적용한 4대 결정
1. **측정맥락 분리** — 혈중·요중·체외피폭·평균·범위·TDI 등 괄호/검체 표현을 `측정맥락` 열로 떼어냄. 물질명은 인자 정체성만 남김.
2. **상위 승격** — `6가크롬·크롬(3가)→크롬 및 그 화합물`, `백석면→석면 분진`, `Benzo(a)pyrene→다환방향족탄화수소`, `총분진·호흡성분진→일반 분진`.
3. **CAS는 레지스트리 것 상속(신규 생성 없음)** — ohsearch가 이미 매칭한 CAS만 사용. 레지스트리 밖 물질은 CAS 공란(`정준명`).
4. **비유해인자는 플래그만** — 생체지표/임상검사/수질지표/평가는 표준명 미부여, `비유해` 열로 분류. 생체지표는 `연관인자`만 병기(마뇨산→톨루엔, 뮤콘산→벤젠, 혈중 알코올→에탄올).

## 컬럼
`원표기 | 측정맥락 | 표준명 | 표준코드 | CAS | IARC | 유형 | 비유해 | 연관인자 | 매핑근거 | 신뢰도 | 사례수 | 측정건수`

- **신뢰도**: `R`=레지스트리 매칭(정확/포함/별표22) · `C`=정준명(레지스트리 외) · `NA`=비유해인자.
- **매핑근거**: 어떤 규칙으로 확정했는지(레지스트리 정확일치 / 동의어사전→X / 별표22 / 포함매칭 / 정준명 / 비유해인자:분류).

## 방법·감사
- 규칙 우선순위: 비유해 판정 → 별표22 규칙(방사선/극저주파) → 동의어사전 → 정준명 → 레지스트리 정확/포함매칭(상위 총칭 선호).
- **포함매칭 31건은 전수 감사**했고 오분류(알코올→IPA, 톨루엔디이소시아네이트→톨루엔, 면분진→석면, 검사류→"검사") 는 동의어사전/비유해로 교정 완료.
- 레지스트리 쓰레기 항목(`검사·간·아농·사상` 등)은 fuzzy 타깃에서 차단.

## 비유해인자 35종 내역
생체지표(대사물질·바이오마커) / 임상검사(CRP·PSA·PD20·유발검사) / 건강결과(혈압·청력) / 수질지표(BOD·SS·탁도) / 평가·방법(OSHA 위험평가) / 오배정(장기명·정상성분).

## 남은 일 (전문가 검수 대상)
1. **표본 검수** — 유형별(금속/용제/물리/혼합/분진) 각 20건 원문 대조.
2. **상위 승격 확인** — 6가크롬을 `크롬 및 그 화합물`로 합쳐도 되는지(발암성 6가 특이성 손실). `측정맥락`에 `6가`가 남아있어 복원 가능.
3. **정준명 37종** — 레지스트리에 없어 새로 지정한 표기(메탄올·나프탈렌·에틸벤젠 등). 레지스트리에 추가할지 결정.
4. **혼합물** — `혼합유기용제`, `트리클로로에틸렌과 톨루엔` 등은 대표 인자로 접었음. 성분 분해가 필요하면 별도.
5. (승인 시) DB 부가필드(`물질_표준·물질_CAS·측정맥락`) 반영 여부 — **아직 미반영**. 원본 `측정값.물질`은 불변.

> 별개 진행 중: `밀폐공간→환기 불량한 공간` 리네임(재시작·epiref·데이터파일 잔여).
